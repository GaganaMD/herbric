# Financial DD Analysis Skill

## Purpose

Transform diligence workbooks, financial metrics, operational KPIs,
and analytical datasets into institutional-quality investor insights.

This skill behaves like:

- preliminary QoE analysis
- institutional diligence analytics
- underwriting preparation
- investment committee support

The workbook is evidence.
Not decoration.

---

# Workbook Rules

When an Excel DD workbook exists:

- treat it as the primary analytical evidence source
- prioritize workbook-derived insights over generic summaries
- read every relevant tab unless explicitly excluded
- identify trends, anomalies, inconsistencies, and risk indicators

Never paste spreadsheet tables directly into slides
unless strategically justified.

---

# Exclusion Rules

If instructed:

- ignore excluded tabs completely
- do not reference excluded tabs in analytics
- do not create charts from excluded tabs

Example:
Ignore tabs 00 and 21.

---

# Metric Transformation Framework

Every material metric must be transformed through this pipeline:

raw metric
→ trend detection
→ benchmark/context
→ operational implication
→ investor implication
→ risk/opportunity interpretation
→ visual communication

Example:

Revenue growth
→ accelerating/slowing?
→ recurring or procurement-lumpy?
→ concentrated?
→ margin-accretive?
→ sustainable?
→ supportive of scalability thesis?

The output must resemble:
investment-underwriting reasoning.

Never:
spreadsheet narration.

---

# Investor Interpretation Requirement

Metrics must be interpreted, not restated.

For every meaningful metric:

- explain why it matters
- identify operational implications
- identify underwriting implications
- identify strategic implications
- identify positive signals if justified
- identify hidden fragility if present

The goal is:
investment interpretation

Not:
spreadsheet reporting

---

# Key Analytical Themes

Actively search for:

- margin instability
- weak cash conversion
- customer concentration
- procurement dependency
- scaling bottlenecks
- operational inefficiency
- governance concerns
- earnings-quality concerns
- receivables stress
- working-capital pressure
- burn-rate fragility
- dilution risk
- execution instability
- inconsistent KPI reporting
- unexplained variance
- low visibility forecasting

---

# Diligence Gap Detection

Missing evidence is itself an analytical finding.

Actively identify:

- missing metrics
- unsupported claims
- absent operational evidence
- KPI inconsistency
- unexplained variance
- weak instrumentation
- low reporting quality

Surface unresolved diligence gaps explicitly.

---

# Analytical Prioritization

Prioritize analytics that materially affect:

- investment conviction
- scalability
- profitability durability
- operational resilience
- capital efficiency
- governance quality
- underwriting confidence

Do not create charts merely because data exists.

Prefer:
fewer high-signal analytics

Over:
exhaustive low-signal coverage

---

# Charting Philosophy

Charts should:

- improve strategic understanding
- reveal operational behavior
- clarify trend/risk
- support investor reasoning

Avoid:

- generic spreadsheet visuals
- cluttered dashboards
- decorative analytics
- chart spam
- low-information graphics

---

# Preferred Visualization Hierarchy

Prefer visuals that reveal:

- trend direction
- concentration
- variance
- margin structure
- contribution mix
- efficiency movement
- bottlenecks
- operational leverage
- capital intensity
- risk accumulation

Preferred chart types:

- waterfall charts
- concentration bars
- bridge analysis
- margin decomposition
- timeline overlays
- cohort trend charts
- KPI cards
- variance analysis
- matrix comparisons
- contribution analysis

Avoid:

- pie chart overuse
- spreadsheet screenshots
- charts without insight
- dense unreadable labels

---

# Slide Transformation Principle

Slides should communicate:

meaning

Not merely:
data

Analytics must become:

- narrative
- underwriting logic
- conviction framing
- investment interpretation

Every chart must justify slide space.

---

# Analytical Density Constraint

Do not overload slides with analytical interpretation.

If a slide becomes:

* visually monotonous
* overly text-heavy
* difficult to scan
* cognitively dense

reduce textual explanation and communicate insight visually instead.

Prefer:

* charts
* KPI blocks
* comparison structures
* concise analytical framing
* visual storytelling

over:

* large analytical paragraphs.

Institutional investor presentations optimize for:

* clarity
* scanability
* presentation cognition
  not:
* maximum written interpretation.


---

# Analytics Code Generation

Generate a structured analytics folder:

analytics/
  tab_name/
    analysis.py
    charts/
    exports/
    notes.md

Each tab pipeline should:

- load workbook data
- clean inconsistencies
- generate meaningful analytics
- create investor-grade visuals
- export reusable assets

Code should be modular, reusable, and auditable.

The final output should resemble:

- PE diligence material
